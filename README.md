# Vidshelf releases

Installers for **Vidshelf**, a private shelf for video links.

Use the [latest release](https://github.com/martinezharo/vidshelf-releases/releases/latest) to download:

- **Windows 10/11:** `Vidshelf-Setup-<version>.exe`
- **Linux:** `Vidshelf-<version>-x86_64.AppImage` or `Vidshelf-<version>-amd64.deb`

The browser lite is available separately in the project's `site/app/` folder. The
application source is kept private; this repository only holds the published
installers.
