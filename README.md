# Vidshelf releases

Installers for **Vidshelf**, a private shelf for video links.

- **Download page:** https://martinezharo.github.io/vidshelf-site/
- **Browser lite:** https://martinezharo.github.io/vidshelf-site/app/
- **Latest release:** https://github.com/martinezharo/vidshelf-releases/releases/latest

## Installers

- **Windows 10/11:** `Vidshelf-Setup-<version>.exe`
- **Linux:** `Vidshelf-<version>-x86_64.AppImage` or `Vidshelf-<version>-amd64.deb`

The application source is kept private; this repository only holds the published
installers.
